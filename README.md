# 风机偏航对中台

现场技师登记机组编号与偏航误差（度）；后台 worker 用数据库行锁认领待处理记录，按 ±1.5° 阈值写入「合格」或「偏航超差」。前端为 Lit 组件 + Vite，接口为 Quart + Hypercorn。

## 编码器校准证书到期禁交

每个出厂号（即机组编号）登记一张编码器校准证书及到期日：

- 证书在有效期内才允许报送；过期或未登记的出厂号，报送一律被拒（过期返 403，提示续期后再报；未登记返 400）。
- 顶栏「编码器到期禁交」专页表格列出各出厂号到期日、有效状态、最近拦截原因/时间、最近续期时间，可展开查看登记/改期/续期/拦截全部留痕。
- 技师可在专页登记出厂号、修改到期日、一键续期一年；到期日顺延记「续期」，提前/缩短记「改期」，二者均留痕。observer 只读。
- **同一口径**：到期有效性不存冗余状态，全部由数据库函数 `encoder_cert_valid(expires_at)` 实时计算，专页查询与报送写口调用同一个函数；报送与续期都先对编码器行 `SELECT … FOR UPDATE` 取行锁再判定，同瞬间争抢只有一种结果（要么放行要么按过期拦截），不会既放行又显示过期。

## 验收

1. 种子数据：机组 W01 误差 0.4° 结论「合格」；机组 W07 误差 3.2° 结论「偏航超差」；W01/W07 均已登记有效期内证书。
2. technician 提交新记录后，列表先显示「待处理」，数秒内 worker 处理后变为对应结论。
3. observer 可查看列表与编码器专页，无提交表单、不能改到期日或续期。
4. 到期禁交主流程：出厂号在有效期内报送被收齐 → 技师把到期日改到昨天，专页立即显示「已过期·禁交」，再报送被 403 拒绝并提示续期（不进待处理队列，写「拦截」留痕，表格显示最近拦截原因）→ 续期后再报送收齐，留痕中可见完整的登记/改期/拦截/续期记录。

## 技术栈

- 后端：Quart、psycopg、`worker.py`（`FOR UPDATE SKIP LOCKED`）、Hypercorn
- 前端：Lit、TypeScript、Vite；生产镜像内 nginx 反代 `/api`
- 镜像源：DaoCloud 基础镜像、清华 PyPI、npmmirror npm
